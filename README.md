# Python Plugin canutils

This plugin runs utilities from [can-utils](https://github.com/linux-can/can-utils).

## Prerequisites

A CAN interface is needed. You can create a virtual CAN interface on your host.

Load the vcan kernel module
```bash
sudo modprobe vcan
```

Create a virtual CAN interface named vcan0
```bash
sudo ip link add dev vcan0 type vcan
```

Bring the interface up
```bash
sudo ip link set up vcan0
```

You will then need to run the container with host networking in order to access the interface from within the container.

## Using the plugin

Get a maintained build from
[quay.io/arcalot/arcaflow-plugin-canutils](https://quay.io/repository/arcalot/arcaflow-plugin-canutils),
or build the container locally:
```
podman build . -t arcaflow-plugin-canutils
```

Run with the provided example input:
```
podman run -i --rm arcaflow-plugin-canutils --net=host -v ./inputs/example_workload.log:/example_workload.log:Z -s player -f - < inputs/canplayer_example.yaml
```
